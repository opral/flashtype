- **Version history.** Save checkpoints of your workspace, browse them in History, see exactly what changed in each file, and restore earlier versions. Checkpoints can carry comments.
- **Comments on your documents.** Comment on any paragraph, heading or list item in a Markdown file. Threads stay attached to their block as the document changes.
- **Review agent changes.** Keep or Undo Claude Code and Codex edits per file or all at once. Undo now reliably restores the previous content, and an agent's terminal tab stays open while you review its changes.
- **CSV tables.** CSV files open as editable tables with typed columns, filters, sorting and saved views. Changes to a CSV show up inline in reviews.
- **Markdown tables.** Insert, delete, move, align and sort rows and columns with grips and menus.
- **Tabs.** Open several documents at once as browser-style tabs.
- **More file types.** Open Excalidraw drawings and videos, alongside images, PDFs and HTML files.
- **Share on Lixray.** Share a file from Flashtype with private repository sync.
- **A colorful file tree** with icons per file type.
- **More reliable opening.** Flashtype recovers from stalled or crashed workspace opens instead of getting stuck, and CSV files open straight from Finder.
